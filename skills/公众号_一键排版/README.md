# 公众号_一键排版

把你写好的文章和图片整理成符合个人习惯的微信公众号排版，并放进配套编辑器，在浏览器中检查手机预览。文章可来自 Obsidian、Markdown、HTML/MHTML 文件、其他本地文档、附件或直接粘贴的内容。

这个 skill 负责读取和编排内容；浏览器里的交互式编辑器由本目录附带的代码提供。**首次使用前，必须先安装编辑器**，否则无法打开编辑页面和手机预览。

## 能做什么

- 按原文顺序保留文字、段落、图片、图注、链接、列表和引用。
- 从 Obsidian 笔记中读取图片嵌入和相对路径；缺失图片时在原位置保留占位提示。
- 按下方排版规范整理标题、正文、金句和图片说明，不改写文章内容。
- 将排版稿载入本地编辑器，在浏览器中查看编辑区和手机预览。
- 提供“复制到公众号”按钮，将富文本复制到微信公众号编辑器。

## 排版规范

| 内容 | 样式 |
| --- | --- |
| 文章标题 | 保留原题；深色、左对齐、加粗。编辑区约 28px，手机预览约 21px。 |
| 正文 | 15px 深灰，字距 1px，行高 1.85，段落底部间距 20px，两端对齐。 |
| 小节标题 | 仅用于独立标题行或完整标题段；20px 黑色粗体，左侧 4px 橙色竖条，文字与竖条同行；上间距 36px、下间距 20px。不要从正文中截取几个字另做标题。 |
| 橙色重点金句 | 橙色加粗，只标短语或有力的小分句；从长句中挑选重点，少量使用，不默认整句或整段加粗。 |
| 图片说明 / 灰色标注 | 12px 灰色、居中，不加橙色线条。图片说明紧跟对应图片；居中不改变段落行高和间距。 |
| 括号图注提示 | 图片后单独成行、用中文或英文括号包住且较短（默认约 40 字以内）的文本，视为该图片的图注。排版时去掉外层括号，显示为 12px 灰色居中；原有行高与段落间距不变。正文中的括号内容或较长文本不按图注处理。 |
| 图片 | 保留原图顺序和比例，默认铺满正文宽度、不加圆角；保留原文中明确的图片占位提示。 |
| 手机预览 | 固定在右侧预览栏，比例 1220:2816；不做编辑区与手机预览的滚动位置校准。 |

应用样式时应转换选中的原文，不重复插入内容。将整段恢复为正文时，恢复正文字号、行距和段距；灰色标注应居中，但不改行高或段距。

## 安装编辑器

先阅读并按步骤安装：[编辑器安装说明](assets/editor/INSTALL.md)。编辑器源代码在 [assets/editor/index.html](assets/editor/index.html)。安装后用 Chrome 或 Edge 打开本地编辑器页面，skill 才能把文章放进编辑区并展示手机预览。

编辑器是无需构建的静态页面，不需要 Node.js、npm 包、账号或公网部署。文章草稿保存在本机浏览器中。附带的编辑器代码只含通用示例，不含用户的旧文章和图片。

## 使用方法

安装 skill 和编辑器后，提供文章即可，例如：

> 请读取 Obsidian《文章标题》，按“公众号_一键排版”的规则排版，在编辑器里展示并打开手机预览。

也可以直接提供文件路径、Markdown/HTML/MHTML 附件，或粘贴图文内容。若图片以 Obsidian 相对路径引用，请保留原有 vault 目录结构，方便读取图片。

处理完成后，检查标题、段落、图片顺序和图注，再点击编辑器左侧的 **复制到公众号**，粘贴到微信公众号后台。

- `agents/openai.yaml`：skill 在 Codex 中显示的名称和描述。
